# Justper Portable BlendShape Injector

Adds baked accessory correction blendshapes to compatible VRChat avatar body meshes during Play Mode and avatar builds.

Install it from the Justper package source in VCC or ALCOM.

## Releasing an update

1. Update the version in `Packages/com.justper.portable-blendshape-injector/package.json`.
2. Commit and push the changes.
3. Run the `Build Release` action on GitHub.
